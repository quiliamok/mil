Mathly in Love (MIL)

Mathly In Love (MIL) is a tool for writing math exams quickly and cleanly (way cleaner than Word), built for high school math teachers.

This little tool exists because my girlfriend teaches high school math, and she was struggling with formulas in Word. Sometimes it lagged, sometimes the sizing broke, sometimes the whole formula just looked wrong. So I decided to give it my best shot, even though my coding knowledge sits at about 3%. What I'm hoping for is that teachers don't have to fight both the exam content and Word at the same time. You type it out, it looks right, you print it, it looks right on paper too. That's genuinely all I wanted.

## What's in here

- **New / Save / Load buttons**: New clears everything for a fresh exam (it double-checks you saved first). Save exports your whole exam to a file. Load opens that file back up so you can keep editing it later. This is basically your question bank.
- **Shuffle**: randomizes the order of questions (and answer choices for MC) without breaking any formatting.
- **Add / Remove template button**: drops in an info block (Name, Period, Time) right before Question 1, or takes it back out if you don't need it.
- **Multiple Choice and Free Response sections**: kept separate and numbered the way you want.
- **Writing space**: add blank lines under a free response question, as much or as little as you need.
- **Page break button**: under each question, in case you'd rather that question start on a fresh page for a cleaner look.
- **Quick Symbols panel**: where the ➕ button opens up a formula box (type math like math, not like typing tricks), there's a graph tool with x and y ranges you can adjust, and an option to upload your own image if a graph you drew somewhere else looks better than what the tool draws.
- **Copy formula button**: on every formula, so you can paste it somewhere else without retyping it.
  Small tip: if you only want to copy part of a formula, right-clicking and using your browser's own copy will grab the raw LaTeX for you.
- **Template settings**: school name, teacher name, course, time, test title, version, and more, all editable.
- **Paper size**: A4 or US Letter, whichever you need.

## How to use it

1. Open the tool in your browser.
2. Set up your Template Settings.
3. Add a question using the Multiple Choice or Free Response buttons.
4. For plain text, just type. For math, click the ➕ in Quick Symbols to open a formula box, then type or click symbols into it.
5. Need a graph? Use the graph tool and adjust the x/y range until it looks right, or upload your own image instead with image button next to graph.
6. Add writing space under free response questions if students need room to work.
7. If a question would look better starting on a new page, use the page break button under it.
8. Want a different question order? Hit Shuffle.
9. Switch to Print Preview to see how it'll look on paper.
10. Print, or save it as a PDF.
11. Hit Save before you close the tab, so you can open this exact exam again later.

## Couple things maybe you want to know (or not)

- It's a single file. No installs, no accounts, just open it and go.
- If it's hosted online somewhere too, that copy won't update by itself. A new version has to be re-uploaded by hand.
- Formulas get quietly converted behind the scenes so they print correctly. You don't need to think about this part, it's just why it works.
